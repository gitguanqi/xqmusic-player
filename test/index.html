    全部场景

    • UMD / 浏览器全局

      经典 <script> 引入 lib/js/xqmusic.min.js：构造、列表、歌词、切歌、静音、无歌词降级、多实例隔离、destroy 生命周期。

    • ESM

      真正的 <script type="module"> 导入 lib/js/xqmusic-utils.mjs，并与 UMD 的 XqMusic.utils 逐项对拍。

    • Vue 3

      挂载预编译的 lib/vue/xqmusic.vue：props 列表、切歌、歌词面板、静音、卸载清理。

    怎么跑

    这些页面必须经 HTTP 打开（fetch 读 mock 数据，file:// 会被浏览器拦截）：

    npm run test:browser　然后打开 http://127.0.0.1:4001/

    每页都会自动执行检查，顶部状态区显示 PASS / FAIL， 下方始终保留一个可交互的实例。机器可读结果在 window.__TEST_RESULTS__。

    想在真实浏览器里一次性跑完四页：node scripts/browser-check.mjs（用本机 Chrome / Edge）。

    命令行等价物

    npm test　纯函数 / 文件契约 / 桩 DOM 行为（含压缩产物）

    npm run build:check　校验提交的 min 产物与源码是否一致
